# Credit Assistant 2.0 - AI-Powered Financial Health Advisor

Industry-Level SaaS FinTech Web Application built for the Indian Financial Ecosystem (BFSI).

## Features
- **Explainable AI Advisor (XAI)**: Gemini API with rule-based fallback in English, Hindi, and Marathi.
- **CIBIL Prediction Engine**: 3-month and 6-month credit score trajectory forecasts.
- **EMI & FOIR Affordability Calculator**: Amortization schedules, DTI, and loan eligibility checks.
- **OCR Bank Statement Scanner**: Automated transaction extraction and risk analysis.
- **Expense Intelligence**: Automatic Indian merchant categorization (Swiggy, Zomato, Amazon, Uber, Blinkit).
- **Fraud Shield**: Anomaly detection and security alerts.
- **Investment Readiness Index**: 0-100 score on emergency fund and savings health.
- **Family Financial Dashboard**: Aggregated household finances.
- **Voice Assistant**: Multilingual voice recognition via Web Speech API.
- **WhatsApp Meta Cloud Simulation**: Simulated conversational banking assistant.
- **SecureShield Security Center**: Active device management and audit logs.

## Quick Start
1. **Backend**:
   - cd backend
   - pip install -r requirements.txt
   - uvicorn app.main:app --reload
2. **Frontend**:
   - cd frontend
   - npm install
   - npm run dev
